# PassionDrivenFruit website

The site is a static Eleventy project. Editable templates, translations, and public assets live in `src/`; `dist/` is generated by the build and is the only directory uploaded by the GitHub Pages workflow. Original image files stay in `source-assets/` and are copied to their legacy public URLs. The optimized WebP versions used by the pages are in `src/assets/`.

## Local development

Requires Node.js 20 or newer.

The checked-in npm lockfile is created with `legacy-peer-deps` enabled because Eleventy’s Nunjucks dependency advertises an optional Chokidar 3 peer while Eleventy uses its Chokidar 4 integration. Keep `.npmrc` in place and use `npm ci` for reproducible installs. When dependency versions change, regenerate the lockfile with `npm install --package-lock-only --legacy-peer-deps`.

```sh
npm ci
npm run build
npm start
```

Open `http://localhost:8080` to review the site. `npm start` serves and watches the Eleventy source. `npm run build` clears and recreates `dist/`, then checks the generated pages, links, metadata, sitemap, responsive CSS rules, public verification files, and image dimensions. `npm run check` reruns those checks against the existing `dist/` output.

## Routes and deployment

The site supports Korean, English, Japanese, and Simplified Chinese. The root (`/`) is the Korean homepage and the canonical Korean URL; `/ko/index.html` remains available as an alias. English lives at `/en/index.html`, while Japanese and Simplified Chinese remain at `/ja/index.html` and `/zh/index.html`. The existing `/index.html`, all localized `index.html` routes, and `/en|ko|ja|zh/Minesweeper.html` and `/en|ko|ja|zh/privacy.html` routes remain available. Each translated page has localized canonical and alternate-language metadata; the Korean root is the default for the homepage and `x-default`. The studio legal pages are Korean source drafts at `/ko/legal/terms.html`, `/ko/legal/privacy.html`, and `/ko/legal/pinfinity-pinferno-consent.html`; the older `/ko/legal/pinballatro-consent.html` path remains as an alias. Stable terms point canonically to the fixed `/ko/legal/draft-3/terms.html` snapshot; the privacy and consent routes remain on their fixed `/ko/legal/draft-2/` snapshots. Historical `draft-1` and `draft-2` snapshots are preserved. Draft pages are marked `noindex` and excluded from the sitemap. They are not connected to live consent settings. See [docs/legal-review-checklist.md](docs/legal-review-checklist.md) for the facts that must be confirmed before publication. The sitemap lists canonical public pages only. The canonical host is `https://pdf-studio.co.kr`.

The GitHub Actions workflow builds and validates `dist/` on pull requests and pushes to `main` or `master`; only pushes and manual runs deploy. In the repository, set **Settings → Pages → Build and deployment → Source** to **GitHub Actions** to enable the workflow deployment.
