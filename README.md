# PassionDrivenFruit website

The site is a static Eleventy project. Editable templates, translations, and public assets live in `src/`; `dist/` is generated by the build and is the only directory uploaded by the GitHub Pages workflow. Original image files stay in `source-assets/` and are copied to their legacy public URLs. The optimized WebP versions used by the pages are in `src/assets/`.

## Local development

Requires Node.js 20 or newer.

The checked-in npm lockfile is created with `legacy-peer-deps` enabled because Eleventy’s Nunjucks dependency advertises an optional Chokidar 3 peer while Eleventy uses its Chokidar 4 integration. Keep `.npmrc` in place and use `npm ci` for reproducible installs. When dependency versions change, regenerate the lockfile with `npm install --package-lock-only --legacy-peer-deps`.

```sh
npm ci
npm run build
npm start
```

Open `http://localhost:8080` to review the site. `npm start` serves and watches the Eleventy source. `npm run build` clears and recreates `dist/`, then checks the generated pages, links, metadata, sitemap, responsive CSS rules, public verification files, and image dimensions. `npm run check` reruns those checks against the existing `dist/` output.

## Routes and deployment

The home page exists in 11 languages (ko, en, ja, zh, vi, fr, es, de, it, pt, ar): `/` is Korean and the canonical default, the others are `/<lang>/index.html`. A language menu sits at the top right of every page (top left in Arabic, which is right-to-left). Home copy lives in `src/_data/site.js`.

Games are shown as trading-card style cards in a horizontal, swipeable rail: name and store "attribute" icon on top, the icon as card art, a type line and short text, and the privacy policy and terms where a card's stats would be. Clicking a card (anywhere but its links) opens a screenshot gallery. There are no game detail pages; the old `/<lang>/Minesweeper.html` URLs redirect to the home page. Card data (store links, icon, text in every language, screenshots) is in each game's `legal-src/games/<id>.js`; screenshots are in `src/assets/games/<id>/`. A game file with `documents: false` (Pinfinity Pinferno for now) gets a card only: no generated terms or privacy policy, so the card shows no document links. A card with no screenshots does not open a gallery, and a coming game can show a release window (`card.release`) in place of "coming soon".

The studio history (연혁) is at `/history.html` (Korean) and `/<lang>/history.html`, linked from the home introduction and every page footer. Events live in `src/_data/history.js`: add an entry with a `YYYY-MM` date, a `kind` (`release` for a game launch, which shows the game's icon, or `milestone`), and a title (optionally a one-line text) in all 11 languages. The page shows year and month only and lists events newest first, grouped by year; the build fails if an event is missing a language.

Each game's terms and privacy policy are built from the shared paragraph library: `/<lang>/legal/<game>/terms.html`, `privacy.html` and `/legal/<game>.json`. Minesweeper's previous policy URLs (`/<lang>/privacy.html`, possibly registered in Play Console) keep serving its current policy. See [docs/legal-review-checklist.md](docs/legal-review-checklist.md).

The Korean studio legal drafts for Pinfinity Pinferno! remain at `/ko/legal/terms.html`, `/ko/legal/privacy.html` and `/ko/legal/pinfinity-pinferno-consent.html` (alias `/ko/legal/pinballatro-consent.html`), with versioned `draft-2` and `draft-3` snapshots (`draft-1`, which used the old project name, was removed). They are `noindex` review drafts. The sitemap lists the home pages and the game documents that are not drafts. The canonical host is `https://pdf-studio.co.kr`.

The GitHub Actions workflow builds and validates `dist/` on pull requests and pushes to `main` or `master`; only pushes and manual runs deploy. In the repository, set **Settings → Pages → Build and deployment → Source** to **GitHub Actions** to enable the workflow deployment.
